# Motorcycle Dashboard

A custom digital dashboard for my **2011 KTM 690 SMC**, built around an ESP32 that talks to the bike's ECU over
automotive protocols (CAN and K-Line).

## Status

🚧 **Coming soon.** I'm still learning how to combine the ESP32 with CAN and K-Line, so there's nothing to show yet.
Code, wiring notes and write-ups will land here as the project takes shape.

## Goals

- Read live data from the bike (RPM, speed, temperatures and more) over K-Line / CAN
- Run it all on an ESP32
- Show it on a custom dashboard that fits the 690 SMC
